# OSD/OS wiki

OSD/OS is a smart TV for CRTs on the Raspberry Pi, drawn like a VCR's on-screen display. The [README](https://github.com/mehmetraif/OSD-OS#readme) has the short version and how to get it; these pages have the rest.

| [The OSD/OS image](https://github.com/mehmetraif/OSD-OS/wiki/The-OSD-OS-Image) | The system for the Raspberry Pi: what it does differently, and how the picture reaches the TV |
| [Modules](https://github.com/mehmetraif/OSD-OS/wiki/Modules) | Local Files, Plex, Jellyfin, Emby, YouTube, Netflix and Prime Video, Playlists, NFC Reader, Weather, Scripts and Ambient:Mode |
| [Themes](https://github.com/mehmetraif/OSD-OS/wiki/Themes) | The eight looks that come with it, and how to make your own |

| [Menu music](https://github.com/mehmetraif/OSD-OS/wiki/Menu-Music) | The tune under the menus: which files it plays, and how |
| [Skins](https://github.com/mehmetraif/OSD-OS/wiki/Skins) | The window's shapes and icons, and how to draw your own |
